# AI-Садовод

**AI-Садовод** — бесплатный AI-помощник для определения растений, болезней и вредителей по фотографии и получения рекомендаций по уходу.

Проект создан для обычных пользователей, занимающихся садом, огородом и дачей. Для работы достаточно загрузить фотографию растения, листа, повреждения или другой проблемы.

## Возможности

AI-Садовод может помочь определить:

* растение по фотографии;
* возможную болезнь;
* возможного вредителя;
* признаки повреждения или другой проблемы;
* основные рекомендации по уходу;
* рекомендации по поливу;
* рекомендации по подкормке;
* другие практические рекомендации, связанные с состоянием растения.

Приложение рассчитано на простое использование без специальных знаний в программировании или ботанике.

> Результаты анализа формируются искусственным интеллектом и могут содержать ошибки. Полученные рекомендации не следует рассматривать как профессиональную консультацию.

## Как работает приложение

1. Пользователь загружает фотографию растения или проблемного участка.
2. Браузер передаёт изображение серверной части приложения.
3. `api.php` формирует запрос к AI API.
4. Запрос отправляется в Groq API.
5. AI-модель анализирует изображение и формирует ответ.
6. Результат возвращается пользователю в удобном виде.

API-ключ не передаётся непосредственно в браузер. Он хранится на сервере в отдельном файле `config.php`, который исключён из Git-репозитория.

## Технологии

Проект использует:

* **HTML** — структура интерфейса;
* **CSS** — оформление интерфейса;
* **JavaScript** — клиентская логика приложения;
* **PHP** — серверная часть и обращение к AI API;
* **Groq API** — API для работы с AI-моделью;
* **Qwen** — используемая AI-модель `qwen/qwen3.6-27b`.

Запросы к Groq выполняются через endpoint:

```text
https://api.groq.com/openai/v1/chat/completions
```

## Установка и развёртывание

Для запуска проекта необходим веб-сервер с поддержкой PHP.

### 1. Скопируйте файлы проекта

Разместите файлы проекта на веб-сервере:

```text
index.html
script.js
style.css
api.php
```

Также должны находиться:

```text
README.md
LICENSE
```

Они необходимы для документации проекта, но не участвуют непосредственно в работе приложения.

### 2. Создайте config.php

В каталоге с `api.php` создайте файл:

```text
config.php
```

Используйте следующую структуру:

```php
<?php
return [
    'groq_api_key' => 'PASTE_YOUR_GROQ_API_KEY_HERE',
];
```

Вместо `PASTE_YOUR_GROQ_API_KEY_HERE` необходимо указать собственный API-ключ Groq.

### 3. Проверьте расположение файлов

`config.php` должен находиться в том же каталоге, что и `api.php`:

```text
project/
├── api.php
├── config.php
├── index.html
├── script.js
└── style.css
```

## Безопасность API-ключа

**Никогда не публикуйте настоящий API-ключ Groq в GitHub.**

API-ключ должен храниться только в серверном файле `config.php`.

Не помещайте секретный ключ:

* в `README.md`;
* в `index.html`;
* в `script.js`;
* в другие клиентские JavaScript-файлы;
* непосредственно в `api.php`;
* в публичные примеры конфигурации;
* в GitHub Issues, Discussions или комментарии к Pull Request.

Файл `config.php` добавлен в `.gitignore` и не должен загружаться в публичный репозиторий.

Если ключ когда-либо случайно попал в публичный репозиторий, его следует считать скомпрометированным и заменить новым ключом в соответствующем сервисе.

## Пример конфигурации

Безопасный пример конфигурации:

```php
<?php
return [
    'groq_api_key' => 'PASTE_YOUR_GROQ_API_KEY_HERE',
];
```

Этот пример **не содержит настоящего API-ключа**.

## API и внешние зависимости

Для работы AI-функций приложение зависит от внешнего сервиса Groq API.

Это означает, что работоспособность AI-анализа зависит, в частности, от:

* доступности Groq API;
* действительности API-ключа;
* доступности используемой AI-модели;
* ограничений и условий соответствующего API;
* сетевого соединения сервера с API.

Сам проект не предоставляет собственную AI-модель.

## Ограничения

AI-Садовод предназначен для информационной и справочной помощи.

Результат анализа фотографии не гарантирует правильное определение растения, болезни или вредителя. Качество результата может зависеть от:

* качества фотографии;
* освещения;
* видимости характерных признаков;
* состояния растения;
* полноты предоставленной информации;
* возможностей используемой AI-модели.

Для важных решений, связанных с лечением растений, применением препаратов или другими потенциально рискованными действиями, информацию следует дополнительно проверять по специализированным источникам.

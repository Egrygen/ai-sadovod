# Участие в проекте

AI-Садовод — открытый проект, и предложения по его улучшению приветствуются.

## Сообщение об ошибке

Если вы обнаружили ошибку:

1. Откройте раздел Issues.
2. Выберите «Сообщение об ошибке».
3. Опишите проблему и ожидаемый результат.
4. При возможности укажите браузер и приложите скриншот.

## Предложение улучшения

Если у вас есть идея для новой возможности:

1. Откройте раздел Issues.
2. Выберите «Предложение улучшения».
3. Опишите предлагаемую возможность.
4. Объясните, какую проблему она решает или чем будет полезна.

## Изменения в коде

Предложения по изменению исходного кода можно оформить через Pull Request.

Перед отправкой Pull Request рекомендуется проверить:

- приложение запускается без ошибок;
- анализ фотографии работает;
- API-ключ не попал в исходный код;
- файл `config.php` не добавлен в репозиторий.

Спасибо всем, кто помогает развивать AI-Садовод.

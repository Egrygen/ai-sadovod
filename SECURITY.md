# Политика безопасности

## Сообщение об уязвимости

Если вы обнаружили уязвимость в AI-Садоводе, пожалуйста, не публикуйте её детали в открытом Issue.

Сообщить о проблеме можно через GitHub, связавшись с владельцем репозитория:

https://github.com/Egrygen

В сообщении укажите:

- краткое описание проблемы;
- шаги для её воспроизведения;
- возможные последствия;
- при необходимости — скриншоты или другие материалы.

## API-ключ

Файл `config.php` с реальным API-ключом Groq не входит в репозиторий и исключён из Git через `.gitignore`.

Для настройки проекта используется файл `config.example.php`, содержащий только пример конфигурации без реального ключа.

Никогда не публикуйте реальные API-ключи, пароли или другие секретные данные в репозитории.

## Поддерживаемые версии

На данный момент поддерживается актуальная версия проекта, опубликованная в репозитории.

Спасибо за помощь в обеспечении безопасности AI-Садовода.
